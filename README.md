# Registry Form

## الوصف
ملف Excel تفاعلي لنماذج التسجيل يحتوي على ماكرو (Registry-Form.xlsm)

## المحتويات
- `Registry-Form.xlsm` - نموذج Excel بصيغة Macro-Enabled لإدارة بيانات التسجيل
- واجهة تفاعلية لإدخال وإدارة البيانات
- يحتوي على ماكرو VBA لأتمتة العمليات

## المتطلبات
- Microsoft Excel 2010 أو أحدث
- تفعيل الماكرو (Macros) في Excel

## طريقة الاستخدام
1. قم بتنزيل ملف `Registry-Form.xlsm`
2. افتح الملف باستخدام Microsoft Excel
3. عند فتح الملف، اضغط على "Enable Macros" لتفعيل الماكرو
4. املأ النموذج بالبيانات المطلوبة

## تحذيرات الأمان
⚠️ هذا الملف يحتوي على ماكرو (Macros). تأكد من مصدر الملف قبل تفعيل الماكرو.
